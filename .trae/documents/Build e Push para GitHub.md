## Verificações
- Checar branch atual e remoto configurado (`git rev-parse --abbrev-ref HEAD`, `git remote -v`).
- Checar alterações pendentes (`git status`).

## Build
- Executar build de produção do pacote `@a-republica/monitor-despesas-next`.

## Commit
- Adicionar todas as mudanças relevantes.
- Commit com mensagem resumindo correções e funcionalidades.

## Tag (opcional)
- Criar uma tag de release descrevendo a versão atual.

## Push
- Enviar commits e tags para o remoto padrão (ex.: `origin <branch>`).
- Caso não exista remoto, configurar com a URL do GitHub e então efetuar o push.

## Resultado
- Confirmar que o repositório está atualizado no GitHub com o build pronto e alterações registradas.
