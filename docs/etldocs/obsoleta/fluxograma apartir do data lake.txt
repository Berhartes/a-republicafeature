  2️⃣ ETL EXTRACT (Extração)

  Funções que fazem download das APIs para o Data Lake

  Arquivo: etl-despesas-deputados.ts
  Função principal: DespesasDeputadosProcessor.extract()

  O que faz:
  1. Chama API: GET /api/v2/deputados?legislatura=57
  2. Para cada deputado: GET /api/v2/deputados/{id}/despesas
  3. Salva dados brutos em: /bancodeDados/congressoNacional/deputados/{id}/despesas.json

  Comando:
  pnpm run etl:despesasDeputados:pc -- 57 100

  5️⃣ ETL LOAD (Carregamento)

  Funções que materializam dados processados

  Arquivo: materialize-unified.ts
  Função principal: materializeSQLite()

  O que faz:
  1. Pega dados processados do Transform
  2. Cria SQLite otimizado: /monitordespesas/monitordespesas.db
  3. Gera JSONs otimizados: /monitordespesas/despesas.json
  4. Cria índices para performance

  Função específica:
  async function materializeSQLite(data: ConsolidatedData) {
    const db = new SQL.Database();

    // Cria schema
    db.exec(`CREATE TABLE fornecedores (...)`);

    // Insere dados processados
    const stmt = db.prepare(`INSERT INTO fornecedores VALUES (...)`);
    data.fornecedores.forEach(f => stmt.run(f));

    // Salva arquivo SQLite
    const buffer = db.export();
    fs.writeFileSync('monitordespesas.db', buffer);
  }

  7️⃣ BACKEND API

  Funções que servem dados materializados

  Arquivo: fornecedores-unified.ts
  Função principal: router.get("/")

  O que faz:
  1. Conecta ao SQLite materializado
  2. Executa queries com filtros dinâmicos
  3. Retorna dados via REST API

  Função específica:
  router.get("/", async (req: Request, res: Response) => {
    const db = await getDatabaseWithFallback(); // ← Conecta SQLite materializado

    const sql = `SELECT * FROM fornecedores WHERE score_suspeicao BETWEEN ? AND ?`;
    const results = db.prepare(sql).all(scoreMin, scoreMax); // ← Query no SQLite

    res.json({ fornecedores: results }); // ← Retorna via API
  });

  ---
  🔄 FLUXO CRONOLÓGICO CORRETO

  1. APIs Externas (dadosabertos.camara.leg.br)
     ↓ [ETL Extract - DespesasDeputadosProcessor.extract()]

  2. Data Lake (/bancodeDados/congressoNacional/deputados/*.json)
     ↓ [ETL Transform - readDeputadosFromLake()]

  3. Dados Processados (/bancodeDados/monitordespesas/*.json)
     ↓ [ETL Load - materializeSQLite()]

  4. SQLite Materializado (monitordespesas.db)
     ↓ [Backend API - fornecedores-unified.ts]

  5. REST API (http://localhost:3333/gastos/fornecedores)
     ↓ [Frontend React - useFornecedoresData()]

  6. Interface do Usuário (localhost:3000)

  A confusão estava na nomenclatura: o "Data Lake" não é a fonte, é o armazenamento intermediário criado pelo ETL
  Extract!
